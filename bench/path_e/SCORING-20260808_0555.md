## Confounds that limit what this run can ratify

**1. The coder role is not settled by this matrix.** The only task the coder cells ran was
`debug`, which is a diagnostic reasoning task, not a code-generation task. c06 and c07 ran
with `think=False` while every competitor ran with thinking enabled and produced 6-9x more
output. Concluding "specialist coder models are weak" from this would be reading a task
mismatch as a capability gap. **No code-writing task exists in the matrix.** Collapsing
both roles onto one model on this evidence is not supported, even though ADR-005's
collapse rule is arithmetically satisfied (35b beats the specialist by 24 points).

**2. The planner verdict rests on n=1 at temperature 1.0.** The 8.5-point planner gap is
driven almost entirely by c03's Option B choice on a single `arch` sample. The planner
preset is temp 1.0 / top_p 0.95 — deliberately high variance. A single draw deciding a
ratification is thin evidence, and a re-draw could plausibly land c03 on Option C.

**3. Every cell reported "started above the 45 C cold target."** The driver records
`gpu_at_start` *after* the warmup request, which itself heats the card, so the cold-start
warning fires unconditionally and carries no information. The cooldown itself worked —
the run log shows 45 C reached before each cell. Harness defect, not a run defect.

**4. c01's warmup was 0.56 s against 4-6 s for every other cell**, because a model was
still resident from the interrupted `0545` run. Affects the load figure only; decode and
prefill are measured after warmup.
