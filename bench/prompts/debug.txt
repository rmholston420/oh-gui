GOAL OF THE SCRIPT
Measure how much VRAM each local model consumes at several context lengths, and decide
which contexts fit entirely on the GPU. The script runs each model at each context, reads
`nvidia-smi` for used VRAM, reads `ollama ps` for the CPU/GPU split, and marks a row
SPILLED if Ollama reports any CPU offload.

The script supports two modes. In `fp16` mode it changes nothing. In `q8` mode it is
supposed to enable flash attention and 8-bit KV-cache quantization first, which should
roughly halve the memory used by the context cache:

    if [[ "$MODE" == "q8" ]]; then
      echo "# restarting Ollama with flash attention + q8_0 KV cache"
      sudo systemctl set-environment OLLAMA_FLASH_ATTENTION=1 OLLAMA_KV_CACHE_TYPE=q8_0
      sudo systemctl restart ollama 2>/dev/null || {
        pkill -x ollama; sleep 2
        OLLAMA_FLASH_ATTENTION=1 OLLAMA_KV_CACHE_TYPE=q8_0 nohup ollama serve >/tmp/ollama.log 2>&1 &
      }
      sleep 6
    fi

    # idle baseline AFTER any restart, with nothing loaded
    for m in "${MODELS[@]}"; do ollama stop "$m" >/dev/null 2>&1; done
    sleep 3
    idle=$(nvidia-smi --query-gpu=memory.used --format=csv,noheader,nounits)

`MODELS` contains exactly two entries: `qwen3.6:27b` and `qwen3-coder:30b`.

After the model sweep, the script performs one extra check: it loads a small embedding
model, `qwen3-embedding:0.6b` (639 MB on disk), and reports what that costs:

    ollama stop qwen3.6:27b >/dev/null 2>&1; sleep 2
    curl -s -X POST http://localhost:11434/api/embed \
      -H 'Content-Type: application/json' \
      -d '{"model":"qwen3-embedding:0.6b","input":"warmup","keep_alive":"2m"}' >/dev/null
    embed_used=$(nvidia-smi --query-gpu=memory.used --format=csv,noheader,nounits)
    echo "embedding resident: used=${embed_used} MiB (cost $(( embed_used - idle )) MiB)"
